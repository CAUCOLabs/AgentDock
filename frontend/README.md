# AisoFlow Frontend

React and Vite dashboard for the AisoFlow FastAPI backend.

## Configuration

Copy `.env.example` to `.env` for local overrides. The default API URL is:

```sh
VITE_AISOFLOW_API_URL=http://127.0.0.1:8000
```

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
